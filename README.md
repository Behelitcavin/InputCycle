# InputCycle · 한영일 원터치 전환 위젯

작은 위젯을 한 번 눌러 한국어·영어·일본어 입력 모드를 순서대로 전환하는 Windows용 도구입니다.

## 다운로드 및 실행

1. [Windows x64 ZIP 다운로드](dist/%ED%95%9C%EC%98%81%EC%9D%BC%20%EC%A0%84%ED%99%98%20%EC%9C%84%EC%A0%AF_Windows%20x64.zip?raw=true)
2. ZIP 파일의 압축을 풉니다.
3. `InputCycle.exe`를 실행합니다. 설치나 관리자 권한은 필요하지 않습니다.

Windows 10·11 64비트용입니다. Windows의 Microsoft 한국어·일본어 입력기를 설정한 PC에서 사용합니다.

## 사용 방법

글을 쓸 곳에 커서를 둔 뒤 위젯을 한 번 누릅니다.

**한글 → 영어(한국어 입력기) → 히라가나 → 영어(일본어 입력기) → 한글**

- 위젯의 큰 글자는 현재 입력 모드, ‘다음’은 누르면 바뀔 모드입니다.
- 일본어 모드에서 `ka`를 입력하면 `か`로 조합됩니다.
- 위젯을 드래그하면 위치가 저장됩니다.
- 원하는 모드로 바로 가거나 종료하려면 위젯을 오른쪽 클릭합니다.

Windows 로그인 때 자동으로 실행하려면 시작프로그램 폴더에 실행 파일의 바로 가기를 추가합니다. 자세한 방법은 [사용법.txt](%EC%82%AC%EC%9A%A9%EB%B2%95.txt)를 참고하세요.

이 저장소는 Windows x64 배포 파일과 사용법을 제공합니다.
