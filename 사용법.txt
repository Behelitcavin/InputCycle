한영일 전환 위젯 | Windows 10·11 (x64)

1. 처음 실행하기
ZIP 파일을 오른쪽 클릭하고 ‘모두 압축 풀기’를 선택하세요. 압축을 푼 폴더에서 InputCycle.exe를 더블클릭하면 화면 오른쪽 아래에 위젯이 나타납니다. 앱 설치나 관리자 권한은 필요 없습니다.

2. 글을 쓰면서 전환하기
글을 쓸 곳에 커서를 둔 뒤 위젯을 한 번 누르세요. 위젯의 큰 글자는 현재 입력 모드이고, ‘다음’은 누르면 바뀔 모드입니다.

한글 → 영어(한국어 입력기) → 히라가나 → 영어(일본어 입력기) → 한글

일본어 모드에서는 ka를 입력하면 か로 조합됩니다. 위젯을 드래그하면 위치가 저장됩니다. 원하는 모드로 바로 가거나 종료하려면 위젯을 오른쪽 클릭하세요.

3. 한국어·일본어 입력기 준비하기
Windows의 Microsoft 한국어·일본어 입력기가 모두 설정되어 있으면 바로 쓸 수 있습니다. 한쪽이 빠져 있다면 Windows 설정에서 ‘언어 설정’을 검색한 뒤 해당 언어를 추가하세요. 언어 옵션의 ‘키보드’에서 Microsoft 입력기를 확인할 수 있습니다.

4. 로그인할 때마다 실행하기 (선택)
압축을 푼 폴더를 계속 사용할 위치에 두세요. InputCycle.exe를 선택하고 Ctrl+C를 누른 뒤, Win+R을 눌러 shell:startup을 입력하고 Enter를 누르세요. 열린 폴더의 빈 곳을 오른쪽 클릭하고 ‘바로 가기 붙여넣기’를 선택하세요. Windows 11에서는 ‘더 많은 옵션 표시’에 있을 수 있습니다. 다음 로그인부터 위젯이 실행됩니다. 자동 실행을 끄려면 같은 폴더에서 해당 바로 가기를 삭제하세요.
